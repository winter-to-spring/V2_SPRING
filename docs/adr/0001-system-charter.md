# ADR-0001: System Charter

## Status
Accepted

## Context
V1 mixed orchestration, runtime coupling, and UI experiments without a stable
product charter. The result was difficult to verify and easy to patch in ways
that increased fragility.

## Decision
V2_SPRING is a clean-room rebuild of a founder-controlled autonomous software
studio. It is not a continuation of the V1 Paperclip product surface.

## Consequences
- We optimize for durable state and governable autonomy first.
- UI polish is not the first milestone.
- Earlier V1 artifacts are treated as archived references, not core building blocks.
